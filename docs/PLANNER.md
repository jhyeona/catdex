# Catdex 작업 플래너

제목과 날짜만 입력하면 주간 달력에 바로 나타나는 개인용 macOS 할 일 앱입니다. 기존 Codex 세션 표시와 함께 동작합니다.

## 시작

```sh
scripts/install-local.sh
open ~/Applications/CatdexMenu.app
```

설치 스크립트는 CLI·앱과 `catdex-capture` 스킬을 설치합니다. 기존 사용자 스킬 파일은 덮어쓰지 않습니다. 새 스킬을 발견하려면 Codex를 다시 실행하세요. 설치 전 개발 빌드를 확인하려면 `swift run CatdexMenu --planner`를 사용합니다.

- 메뉴바 → **작업 플래너…**: 전체 작업창
- **+ 할 일** 또는 **⌃⌥K**: 제목과 날짜를 입력하고 바로 추가
- 작은 패널 → **세션 / 오늘**: 세션 상태와 오늘 할 일 전환
- **더보기 → 설정**: 필요한 경우에만 단축키·알림·자동 시간 추천 조건 설정

## 기본 사용법

1. 원하는 요일 아래 **+ 추가** 또는 상단 **+ 할 일**을 누릅니다.
2. 제목을 적고 날짜를 고른 뒤 **추가**를 누릅니다. 기록함 확인이나 일정 확정 없이 바로 달력에 나타납니다.
3. 끝낸 일은 제목 왼쪽의 동그라미를 눌러 완료합니다. **완료한 일**에서 다시 확인할 수 있습니다.

주간 달력과 전체 할 일 목록에서 카드의 **↑·↓** 버튼으로 한 칸씩 옮기거나, 카드를 드래그해 원하는 위치의 파란 삽입선에 놓으면 순서가 바뀝니다. 변경한 순서는 자동 저장되며 앱을 다시 켜도 유지됩니다. 새 할 일은 기존 목록 뒤에 추가됩니다. 별표가 있는 작업도 직접 정한 순서를 따르며 핵심 작업 지정은 유지됩니다.

다른 요일로 드래그하면 날짜와 순서를 함께 옮깁니다. 같은 날짜 안에서 순서만 바꾸면 지정한 시간이 유지됩니다. 날짜를 바꾸면 이전 날짜의 시간 배치는 해제됩니다. 제목을 클릭하면 제목·날짜·메모를 수정할 수 있습니다. 주간 달력에는 해당 날짜의 할 일을 표시하며 시간 미지정 작업도 보입니다. 기본 화면에는 점심·시간 격자·후보 등록·프로젝트 입력이 없습니다.

## 메모·대화 기록 (선택)

**더보기 → 메모 남기기**에서 `/기록 내일 오전 로그인 버그 확인 40분 예상`처럼 입력합니다. `/기록` 접두사는 생략해도 됩니다. 프로젝트는 선택한 폴더로 연결합니다.

원문은 즉시 로컬에 보존됩니다. 기록함에서 후보의 제목·작업할 날짜·마감·예상시간·희망 시간대를 수정하고 필요한 후보만 선택해 등록하세요. **메모로 보관**은 할 일을 만들지 않습니다. 자동으로 후보를 찾지 못하면 **후보 직접 추가**를 사용합니다. 확인한 기록과 미선택 후보의 원문도 기록함에 남습니다.

독립 입력은 오프라인 규칙으로 오늘·내일·모레·요일·오전/오후·소요시간을 인식합니다. 여러 날짜나 모호한 시간은 사용자가 확인합니다. `내일 오전에 확인`은 희망 작업 시간이며 마감이 아닙니다. `금요일까지 리뷰`는 마감입니다. 시간대는 Mac의 로컬 시간대를 사용합니다.

Codex 대화에서는 `/skills` → **catdex-capture**를 선택하고 기록을 요청합니다. 스킬은 프로젝트, 세션 참조, 필요한 대화 발췌 또는 요약과 후보를 저장합니다. `/기록`은 Catdex 입력창의 문법이며 Codex의 기본 슬래시 명령으로 등록하지 않습니다.

## 일정 관리

달력은 **월요일–일요일 1주일**을 보여줍니다. 상단 화살표로 이전·다음 주로 이동하고 **이번 주**로 돌아옵니다. 시간까지 정하고 싶을 때만 **일정 도구 → 시간표 보기**를 켭니다. 날짜 머리글을 고른 뒤 **일정 도구 → 선택한 날짜에 시간 추천**을 누릅니다. 선택한 날짜의 작업, 해당 날짜까지 마감인 작업, 핵심으로 고정한 미완료 작업을 대상으로 합니다. 대기 중인 작업은 배치하지 않습니다.

기본 업무시간은 평일 09–18시, 점심 12–13시, 작업 사이 여유 10분입니다. 마감 → 우선순위 → 사용자 목록 순서로 추천하고 예상시간 미입력 작업은 30분으로 가정합니다. 빈 시간에 넣을 수 없는 작업은 사유를 표시합니다. 목록 우클릭의 **목록 맨 위로**로 추천 순서를 바꿀 수 있습니다.

추천 시작 시간을 수정하거나 항목을 제외한 뒤 **일정 확정**을 누르세요. 업무시간·점심·희망 시간대·마감·여유시간을 벗어나면 확정하지 않습니다. 추천 중 다른 창이나 CLI가 작업을 변경하면 다시 계산해야 합니다.

- 목록의 작업을 원하는 요일·시간 칸으로 드래그: 해당 날짜에 직접 배치. 예상시간이 없으면 30분 사용.
- 기존 일정을 클릭: 시작·종료 수정, 삭제. 직접 배치는 업무시간 밖도 허용하지만 다른 일정과 겹치지 않아야 합니다.
- **고정 일정**: 회의 등 직접 입력. 여러 날에 걸친 일정도 추천에서 점유 시간으로 취급합니다.
- **밀린 작업 다시 배치**: 종료 시간이 지난 미완료 작업만 추천 대상에 다시 포함. 승인한 대체 일정만 반영하며 기존 미래 일정은 유지합니다.
- **내일 하기 / 내일로 미루기**: 작업 날짜를 내일로 변경하고 핵심 고정을 해제합니다. 기존 날짜와 맞지 않는 배치는 해제되며 새 시간은 다시 추천받습니다.

시작 알림은 확정된 미래 작업에 예약됩니다. 최초 예약 시 macOS 알림 권한을 요청합니다. 알림의 **10분 뒤 알림**은 일정 자체를 변경하지 않습니다. 권한이 없어도 목록·시간표를 사용할 수 있습니다. 절전 중 알림 전달 시점은 macOS에 따르며, 앱 활성화·잠자기 복귀 시 알림 권한과 예약을 다시 확인합니다. 이미 예약한 미완료 작업의 알림은 시간이 지났다는 이유만으로 취소하지 않습니다. 완료·대기 작업은 시작 알림에서 제외됩니다. 알림은 앱 번들에서 지원합니다.

## 작업 맥락과 저장

작업 상세에서 중단 메모, 설명, 체크리스트, 상태, 우선순위를 수정하고 **변경 저장**을 누릅니다. **프로젝트 열기**와 **이어가기 문맥 복사**로 다시 시작할 수 있습니다. 원본 Codex 세션이 삭제되어도 저장한 발췌는 남습니다. Codex 세션 종료만으로 할 일이 완료되지는 않습니다.

데이터는 `~/.codex/cat-status/planner.sqlite`에 저장하며 `CATDEX_STATUS_DIR`로 변경할 수 있습니다. SQLite WAL과 트랜잭션으로 앱·CLI 동시 쓰기를 처리합니다. `catdex cleanup`은 플래너 데이터를 삭제하지 않습니다. 백업은 앱·CLI를 종료한 뒤 DB 파일을 복사하거나 SQLite backup API를 사용하세요. 동작 중인 DB 파일만 복사하면 WAL의 최근 변경을 놓칠 수 있습니다.

이 버전에는 외부 캘린더·동기화·팀 협업·타이머·반복 할 일·자동 코드 실행이 없습니다.

## CLI 인터페이스

```sh
catdex capture --json < request.json
```

필수 필드: `requestID`(재시도 때 같은 UUID), `text`(원문). 선택 필드: `project`, `sessionID`, `context`, `candidates`. 날짜는 시간대가 포함된 ISO 8601입니다. 후보 상세와 예제는 [기록 스킬](../skills/catdex-capture/SKILL.md)에 있습니다. `candidates` 생략은 오프라인 추출, 빈 배열은 메모로 저장합니다. 후보 오류가 있어도 유효한 원문은 남고 유효한 후보만 제안됩니다.

성공: `{"ok":true,"recordID":"...","candidateCount":1}`와 종료 코드 0. 실패: `{"ok":false,"error":"..."}`와 종료 코드 1. 같은 requestID 재전송은 최초 기록을 반환하며 후보를 다시 생성하지 않습니다. 다른 원문·프로젝트·세션·맥락에 같은 ID를 재사용하면 실패합니다.

단위 테스트는 원문 보존·부분 등록·날짜 인식·동시 수정·배치 제약·명시적 재배치를 검증합니다. CLI 검사는 임시 DB에 여러 프로세스를 동시에 실행해 재시도 중복 방지와 세션 정리 격리를 확인합니다.


### 2026-10-06 설치 환경 검증

`~/Applications/CatdexMenu.app`과 기본 로컬 DB에서 검증용 기록을 생성하여 다음 흐름을 직접 확인했습니다.

- 빠른 기록 저장 → 후보 확인 → 오늘 할 일 등록
- 시간 배치 추천 → 확정 → 일정 편집창에서 시작·종료 변경 및 저장
- 앱 재실행 뒤 작업·일정·설정 유지
- 시스템 설정이 활성화된 상태에서 macOS 키 이벤트로 ⌃⌥K 입력 → 빠른 기록창 열림
- 작업 카드 여백에서 시간표 16시로 실제 드래그 → 16:00–16:05 배치
- 수정본의 제목 위에서 시간표 17시로 실제 드래그 → 17:00–17:05 이동, 제목 클릭 → 상세 열림
- 검증용 작업 완료 처리 → 오늘 목록에서 제외

실사용 중 발견하여 수정한 문제:

1. ⌃⌥Space가 macOS 입력 소스 전환 단축키와 겹쳐 기본값을 ⌃⌥K로 변경했습니다.
2. 실행파일만 서명하던 빌드를 앱 번들 전체 서명으로 변경했습니다. 이후 시스템 알림 권한 요청과 시스템 설정의 CatdexMenu 항목 등록을 확인했습니다.
3. 제목 버튼이 카드의 드래그 입력을 가로채던 문제를 수정했습니다. 제목 클릭과 접근성 동작을 유지하면서 드래그를 함께 처리합니다.
4. 앱 활성화·잠자기 복귀 시 권한과 예약을 다시 확인하고, 이미 예약한 미완료 알림을 시간이 지났다는 이유로 취소하지 않도록 수정했습니다. 권한 대기·거부 상태도 구분합니다.

사용자 승인 후 Catdex 알림을 허용했습니다. 검증용 작업을 15:28에 예약했고 macOS `usernoted` 로그에서 15:28:00에 배너·잠금 화면·알림 센터로 실제 전달된 것을 확인했습니다. 자동화 도구가 알림 센터의 다른 위젯 창을 반환하여 배너 화면과 알림의 버튼 클릭은 직접 확인하지 못했습니다. **10분 뒤 다시 알림 및 실제 Mac 잠자기 후 전달은 미검증**입니다.

기본 화면 도구의 `noWindowsAvailable` 오류 때문에 사용자 승인 후 임시 전용 도구로 실제 macOS 드래그·키 입력을 전송했습니다. macOS 권한 목록에 전용 도구의 독립 항목이 등록되지 않아 개별 권한 회수 명령은 적용되지 않았습니다. 기존 앱 권한은 변경하지 않고 검증용 임시 앱을 제거했습니다. 검증용 기록과 완료 작업 1개는 확인 근거로 남아 있습니다.
